## What it does

TreeSize Free analyzes storage usage and helps you find which files and folders take up space. Scan a drive or folder, explore the results from the folder level down to individual files, and use the visual treemap to spot large items quickly.

| Feature | Description |
| --- | --- |
| **Storage overview** | See folder sizes and how space is distributed |
| **Treemap view** | Find large files and directories visually |
| **PDF reports** | Create a report of disk space usage |
| **Windows Explorer-style browsing** | Navigate scan results in a familiar folder structure |

## Typical uses

- Find folders or files consuming most of a drive
- Review storage before moving or cleaning up data
- Compare large directories visually using the treemap
- Save a PDF overview of disk space usage
